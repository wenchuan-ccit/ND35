微積分常用技巧總整理

微分與積分是工程數學的基礎。本指南提供互動式的學習體驗，幫助您快速掌握核心技巧。

第一部分：微分

微分的核心是求出函數的「導函數」(Derivative)，它代表了函數在特定點上的瞬間變化率或切線斜率。這是在分析系統動態行為時不可或缺的工具。

基礎微分公式

$$\frac{d}{dx}(x^n) = nx^{n-1}$$
$$\frac{d}{dx}(\sin x) = \cos x$$
$$\frac{d}{dx}(\cos x) = -\sin x$$
$$\frac{d}{dx}(\tan x) = \sec^2 x$$
$$\frac{d}{dx}(e^x) = e^x$$
$$\frac{d}{dx}(\ln x) = \frac{1}{x}$$

第二部分：積分

積分可以視為微分的逆運算，主要應用於計算變化過程中的「累積總量」，例如曲線下的面積、物體的體積或隨時間累積的總位移等。

基礎積分公式

$$\int x^n \,dx = \frac{x^{n+1}}{n+1} + C$$
$$\int \cos x \,dx = \sin x + C$$
$$\int \sin x \,dx = -\cos x + C$$
$$\int e^x \,dx = e^x + C$$
$$\int \frac{1}{x} \,dx = \ln|x| + C$$
